# DataSafe Project Memory

- 2026-05-22: After beta55 scheduler validation, `automationSettingsChanged` now treats `reminders.staleDays` as an automation setting so saving the reminder threshold refreshes Windows scheduled tasks and shows the same update result path as other automation changes.
- 2026-05-22: A beta56 screenshot showed `Register-ScheduledTask` access denied on `OneBiteBackupCatchUp` while creating the startup/logon catch-up task. Beta57 keeps sign-in catch-up for normal users and only adds the startup trigger when running elevated.
- 2026-05-22: Beta58 made update discovery proactive: DataSafe now checks for updates at startup and every 6 hours while running, then shows one in-app update prompt per available version with Download Update and Later actions.
- 2026-05-22: A test machine with only app shortcuts on Desktop exposed the Windows Desktop overlay split: `%USERPROFILE%\Desktop` only captured the user shortcut while app installers had placed shared shortcuts under `C:\Users\Public\Desktop`. Beta59 marks Desktop jobs with `includePublicDesktop` and merges Public Desktop into Desktop backups.
- 2026-05-22: Beta60 extended the common-folder fix to Documents and Pictures by tagging jobs with Windows known-folder names, resolving redirected OneDrive/known-folder paths at backup time, and merging matching `C:\Users\Public` folders when present.
- 2026-05-28: Screenshots from beta60 showed raw PowerShell text for Task Scheduler access denied, status-file `WriteAllText`, and overlapping backup cases. Beta61 keeps the good/expected errors but translates them into customer-friendly wait/retry/contact guidance and treats catch-up/reminder task registration as best-effort.
